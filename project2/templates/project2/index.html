Project 2

Explainability

Interpretability and complexity on the Palmer Penguins dataset: the regularisation trade-off, counterfactuals, and feature effect plots.

This app is being ported from a standalone Gradio prototype into this Django project. The prototype implements all five tasks; the work here is the port and the corrections listed below.

Tasks

  1. Fit a decision tree; show the tree, its test accuracy and its number of leaves.
  2. Add a λ slider selecting the model that maximises accuracy − Ω(f).
  3. Repeat for logistic regression with a suitable complexity measure Ω.
  4. Counterfactual explanations, ranked by MAD-weighted L1 distance.
  5. PDP and ALE plots, written from scratch, one curve per species.

Remaining work

  • Port the Gradio callbacks to Django views rendering saved figures.
  • Remove multi_class="multinomial", removed in scikit-learn 1.7.
  • Implement the exact-gradient ALE branch for logistic regression, or correct the claim.
  • Perturb only a subset of features per sample so counterfactuals can be sparse.
  • One-hot encode island instead of passing it as an ordinal.
